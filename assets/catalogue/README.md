# PMU Product Catalogue

## Important Note

Please place your PMU product catalogue PDF file in this directory with the name:
`pmu-catalogue.pdf`

The download button on the PMU product page (`consumable/pmu-product.html`) links to:
`../assets/catalogue/pmu-catalogue.pdf`

When users click the "Download Catalogue" button, the PDF will open in a new tab where they can view and download it.

## File Requirements
- File name: `pmu-catalogue.pdf`
- Location: `assets/catalogue/`
- Format: PDF
- Recommended size: Under 10MB for faster loading
